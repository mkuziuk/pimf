A small library for one-dimensional signals

Intrinsic multiscale filtering

Separate a signal into progressively finer components. Choose a local weighted mean or a robust location fit, using the same decomposition API.

y=S1 + S2 + ··· + SK+rK+1 observationcomponents, coarse to fineremaining residual

Each stage smooths the current residual and subtracts that component before the next stage. The contrast defines the local estimator; the kernel defines the sample weights. Reconstruction retains the complete observation, including noise. A denoising application must decide which components to keep.

01 / First decomposition

Install & quickstart

This documentation describes the 0.2 development API. Install the implementation branch to use it. The current PyPI release has the original function API.

pip install "pimf @ git+https://github.com/mkuziuk/pimf@codex/imf-object-api"
import numpy as np
from pimf import IMF
from pimf.contrasts import SmoothAbs
from pimf.kernels import epanechnikov

t = np.arange(1000) / 1000
rng = np.random.default_rng(0)
y = np.sin(2 * np.pi * t) + rng.normal(0, 0.1, len(t))

method = IMF(contrast=SmoothAbs(H=0.2), kernel=epanechnikov)
result = method.decompose(y, h1=0.25, a=np.sqrt(2), k_max=8)

assert result.imfs.shape == (8, 1000)
np.testing.assert_allclose(result.reconstruction, y, rtol=0, atol=1e-12)

IMF() defaults to a quadratic contrast and the squared-triangular kernel. Reuse a configured object across signals; every call returns an independent result.

linear = IMF().decompose(y)
second_result = method.decompose(y, h1=0.15, k_max=5)

02 / Choose the scales

Window schedule

The data are treated as equally spaced on a unit time domain, with spacing 1 / len(y). A bandwidth h is a half-width: the neighborhood is [t − h, t + h]. It is independent of the robust contrast scale H.

hk+1 = hk / a
ArgumentDefaultMeaning
h10.25First half-width, in (0, 0.5]. The default covers about half the samples.
asqrt(2)Finite shrink factor greater than one. The paper suggests values up to two.
k_max8Maximum number of components. A positive integer, or None when h_min is supplied.
h_minNoneOptional minimum half-width in (0, h1], inclusive.
window_sizesNoneAlternative explicit sequence of positive odd sample counts.

With 1,000 samples, h1=0.25 gives a 501-sample first window. A fractional sample radius uses an odd window large enough to contain the kernel support. Weights use the fractional bandwidth, not the outward-rounded support radius. Radii within 10−9 samples of a positive integer snap to that integer in both the support and the weights, avoiding floating-point boundary errors. Consecutive support sizes can coincide while their weights differ.

Stop at the first applicable limit: the component cap, a next bandwidth below h_min, or completion of a window containing only the center sample. A center-only window is represented by size one. The actual component count can therefore be smaller than k_max. Eight is a library default, not a theoretical optimum.

# A fixed maximum number of scales.
four_scales = method.decompose(y, h1=0.2, a=2, k_max=4)

# Stop by bandwidth alone.
to_minimum = method.decompose(y, k_max=None, h_min=0.02)

# Reproduce a chosen integer-window experiment.
explicit = method.decompose(y, window_sizes=[151, 75, 31])
Explicit windows define the entire schedule. Their kernel radius is (window_size - 1) / 2. Do not combine them with nondefault h1, a, k_max or any h_min. Empty, even and nonintegral window sizes raise ValueError.

Kernels

Import a ready-to-use kernel and pass it directly to IMF. Kernels have compact support on [−1, 1], and the library normalizes their sampled weights to sum to one.

from pimf.kernels import epanechnikov, squared_triangle, triangle, uniform

weighted_mean = IMF(kernel=epanechnikov).decompose(y)
weights = epanechnikov.weights(31)

The classes are also available for explicit construction. The lowercase instances carry no parameters or cached signal data.

A naming correction. The research paper calls ¾ (1 − |u|)² “Epanechnikov.” We name that profile squared_triangle and keep it as the default. epanechnikov denotes the classical ¾ (1 − u²) kernel.

Contrasts

A contrast determines the local location estimate at each sample. Its parameters belong to the contrast object.

Quadratic()

The loss is ρ(r) = r²/2. Its minimizer is the weighted local mean, computed directly without gradient descent.

SmoothAbs(H)

A Gaussian-smoothed absolute loss with bounded score. Smaller H is more median-like; larger H approaches a local mean.

from pimf.contrasts import Quadratic, SmoothAbs

linear_method = IMF(contrast=Quadratic())
robust_method = IMF(contrast=SmoothAbs(H=0.2))

H must be finite and positive. It has the same units as the signal values. The paper recommends a value of the same order as the uncontaminated noise standard deviation; the research examples often use H = 2 * sigma. The library does not estimate the noise or choose H automatically.

The score is erf(r / (sqrt(2) * H)), evaluated with the research's Abramowitz–Stegun approximation. The positive curvature bound is sqrt(2 / pi) / H. No lookup table is used.

Boundaries & convergence

boundary="wrap" is the default and matches the paper's periodic extension. The setting is passed to numpy.pad; "reflect" and "edge" also work.

careful = IMF(
    contrast=SmoothAbs(H=0.2),
    kernel=epanechnikov,
    boundary="reflect",
    max_iter=200,
    tol=1e-8,
)
careful_result = careful.decompose(y, k_max=6)

For contrasts without a direct solver, the library starts from each window's median and performs clipped gradient descent. Its step is 0.95 / contrast.curvature(). An iteration stops the stage when the maximum update is at most tol * (1 + max(abs(component))).

max_iter limits optimization iterations within each stage. k_max limits the number of decomposition stages. If optimization reaches its limit without meeting the tolerance, the stage reports converged=False. Closed-form stages report iterations=1, final_max_delta=nan and converged=True.

03 / Python reference

Python API

IMF

IMF(contrast=None, kernel=None, *, boundary="wrap", max_iter=60, tol=1e-6)

IMF.decompose(y, *, h1=0.25, a=sqrt(2), k_max=8,
              h_min=None, window_sizes=None) -> IMFResult

None selects Quadratic() and squared_triangle. Input y must be nonempty, finite and one-dimensional; it is converted to floating point. The input is not modified. Constructor settings are reusable across calls. Invalid numerical settings raise ValueError.

Kernel

kernel.profile(u)
kernel.weights(window_size, *, bandwidth=None)
kernel(window_size, *, bandwidth=None)

profile(u) returns an array of finite nonnegative values matching u. The base class evaluates only points inside [−1, 1], fills other weights with zero and normalizes the result. The sampled weights must have a positive sum.

Here bandwidth is a radius in samples, unlike the normalized half-widths passed to decompose. Omitting it uses the integer window radius. A one-sample window has weight one.

Contrast

contrast(r)                      # loss rho(r)
contrast.psi(r)                  # score rho'(r)
contrast.curvature()             # positive global upper bound on rho''
contrast.solve(windows, weights) # optional direct minimizer

Loss and score methods must accept NumPy arrays. A direct solver receives rows of local observations and a normalized weight vector, and returns one estimate per row. Without a direct solver, supply a finite positive curvature bound for a convex differentiable contrast.

IMFResult and StageInfo

Both are small dataclasses exported from pimf. IMFResult holds the arrays and the schedule; StageInfo holds the diagnostics listed under Reading the result. The configured IMF never stores a signal or the last result.

Custom kernels & contrasts

Subclass Kernel and define a profile. The base class handles sampling, compact support and normalization.

from pimf import Kernel

class Cosine(Kernel):
    def profile(self, u):
        return np.cos(np.pi * u / 2)

cosine_result = IMF(kernel=Cosine()).decompose(y)

A custom contrast supplies its loss, score and curvature bound. This Huber example uses the general gradient descent path:

from pimf import Contrast

class Huber(Contrast):
    def __init__(self, delta):
        if not np.isfinite(delta) or delta <= 0:
            raise ValueError("delta must be finite and positive")
        self.delta = delta

    def __call__(self, r):
        r = np.asarray(r, dtype=float)
        magnitude = np.abs(r)
        return np.where(
            magnitude <= self.delta,
            0.5 * r**2,
            self.delta * (magnitude - 0.5 * self.delta),
        )

    def psi(self, r):
        return np.clip(r, -self.delta, self.delta)

    def curvature(self):
        return 1.0

huber_result = IMF(contrast=Huber(0.3)).decompose(y)

The solver supports this contrast, but the paper's higher-order smoothness guarantees do not apply to the Huber loss unchanged. Custom profiles and contrasts should be checked against independent reference calculations.

Migrating from functions

The function API remains available as a small compatibility layer over the same implementation. Existing defaults still use the research integer-window schedule, with a minimum window of 31 and a size-dependent component count.

from pimf import make_window_schedule, robust_imf

old_result = robust_imf(y, h=0.2)
same_result = IMF(SmoothAbs(H=0.2)).decompose(
    y, window_sizes=make_window_schedule(len(y))
)
np.testing.assert_array_equal(old_result.imfs, same_result.imfs)

imf(), linear_imf(), robust_imf() and make_window_schedule() remain supported. SmoothAbs(0.2) and SmoothAbs(h=0.2) remain valid; supplying both H and h raises ValueError.

The new default schedule is different. IMF().decompose(y) uses up to eight exact fractional bandwidths. An integer-window schedule shrinks and rounds sample counts at each step. Use explicit windows for numerical reproduction, even when the two schedules have similar support sizes.

Research & numerics

The IMF research repository contains the reference notebooks, the paper and the solver benchmark. This library preserves the research erf approximation and uses vectorized NumPy without application-level threading.

The benchmark compares a lookup-based research solver with QuantLet's scalar search. Its threaded speedups are not performance measurements of pimf. The library tests use research fixtures to check numerical agreement and reconstruction.

Reconstruction is accurate to floating-point rounding. It does not establish signal recovery quality. The usefulness of a decomposition depends on the kernel, contrast, scales and contamination model.
