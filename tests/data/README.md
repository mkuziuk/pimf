# Solver reference fixture

`solver_reference.npz` contains the observations and single-thread QuantLet
reference components from `mkuziuk/imf` commit
`0ba4c72`, `experiments/solver-speed/results/`:

- `your_gd_1000_example.npz`: H=0.4, squared-triangular kernel, the original
  integer-window schedule, seed 777.
- `quantlet_zero_2000_example.npz`: H=1, classical Epanechnikov kernel,
  h1=0.2, a=sqrt(2), eight bandwidths, zero replacement, seed 2026.

The arrays are copied without modification. Only unused clean signals, time
grids and lookup-GD outputs are omitted. The scalar reference uses the QuantLet
solver recorded at commit `58d6762cccbdce3abe5e183ceaf9564bf46768ca` in the
research benchmark metadata. The benchmark checks convergence and agreement
before saving its reference outputs.

These are tolerance-based cross-solver fixtures. The existing regression
tests separately preserve the direct-erf notebook's numerical values.

# Lookup reference fixture

`lookup_reference.npz` is generated by running the original functions in
`experiments/gd-irmf/gd_irmf.ipynb` at research commit
`0ba4c723d4c2abddeb3c5a1ac14c8ff93cc0e6d0`. It contains:

- Standardized residuals spanning [-10, 10], every grid node, midpoints, and
  values immediately outside the [-8, 8] lookup interval.
- The notebook's `np.interp` score and loss at H=1, plus direct evaluations.
- All nine lookup-GD components, the final residual and iteration counts for
  the existing `your_gd_1000_y` observation at H=0.4.

Generation checks the lookup approximation against direct evaluation and the
components against the independent scalar-solver fixture. Tests compare the
library's arithmetic indexing against these saved research outputs, including
multiple H values and parallel decompositions. Cross-platform floating-point
roundoff is allowed with explicit tolerances.

Regenerate from an unchanged checkout of that research commit:

```sh
uv run python tests/data/generate_lookup_reference.py /path/to/imf
```
